# SkillMatch — Freelance Marketplace Platform

SkillMatch is a full-stack freelance marketplace designed to connect clients with verified independent professionals. The platform ensures quality and trust through built-in skill verification tests, portfolio showcases, and a secure project workflow.

## 👥 Stakeholders & Core Features

### 🛠️ Admin
* **Account Management:** Approve or suspend freelancer and client accounts to maintain platform integrity.
* **Category & Question Banks:** Manage skill categories and curate quiz/question banks for verifications.
* **Analytics & Reporting:** Monitor platform statistics and generate downloadable PDF reports.

### 💻 Freelancers
* **Profiles & Portfolios:** Showcase professional background with portfolio items and GitHub links.
* **Skill Verification:** Select skill categories and take tests to earn verified badges.
* **Workflow:** Apply for jobs, submit completed work, and chat with clients in real-time.
* **Growth Insights:** Receive automated skill improvement suggestions based on test performance.

### 🤝 Clients
* **Job Posting & Proposals:** Create project postings and review incoming proposals from freelancers.
* **Smart Discovery:** Sort and filter freelancers by their official skill test scores.
* **Project Management:** Approve deliverables, rate completed work, and communicate directly via chat.

### 🌐 Guests
* **Discovery:** Browse public freelancer profiles and view active job listings without an account.
